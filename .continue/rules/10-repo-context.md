---
name: DevDeck - Context acquisition rules
---

Before implementing any feature or making edits:

1) Explore the codebase using built-in tools:
   - List relevant files and directories
   - Search for the UI entry points and language config loader
   - Identify where build/run commands are defined or should be defined

2) In your response, always name the exact files you inspected (e.g., main.cpp, mainwindow.*, lang/*.json, CMakeLists.txt).

3) If you cannot find the relevant files, stop and say: "I need you to open the repository folder in VS Code and ensure Continue can read files."

Do not guess based on the project name.
