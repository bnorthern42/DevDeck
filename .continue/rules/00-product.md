---
name: DevDeck - Product definition
---

DevDeck is a desktop code playground app (like https://playcode.io/cpp-playground), NOT a slide deck/presentation tool.

Core UX:
- Central code editor
- Language selector (multi-language)
- Build/Run buttons
- Output/console panel capturing stdout/stderr and exit codes
- Language toolchains are driven by JSON definitions in lang/

Forbidden topics/features:
- slides, slide decks, presentations, PowerPoint, exporting decks, speaker notes
