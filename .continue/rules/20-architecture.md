name: DevDeck - Architecture constraints
---

Finish the project into a working MVP.

You may refactor and create helper files when needed, but do NOT do a ground-up rewrite.
Prefer implementing missing end-to-end functionality over cosmetic refactors.

When changing behavior:
- keep UI structure intact unless it blocks functionality
- keep build system (CMake) working at all times
- add basic error handling and clear messages in the UI
